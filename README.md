# Task 6 – Sales Trend Analysis Using SQL

## Objective
Analyze monthly revenue and order volume using SQL aggregation functions.

## Tools Used
- MySQL
- MySQL Workbench

## Dataset
Online Sales dataset containing transaction details, dates, product information, revenue, region, and payment method.

## Analysis Performed
- Extracted year and month from transaction dates
- Calculated monthly revenue using SUM()
- Calculated order volume using COUNT(DISTINCT)
- Grouped results by year and month
- Sorted results using ORDER BY
- Filtered the analysis for the year 2024

## Deliverables
- SQL script
- Results table screenshot
